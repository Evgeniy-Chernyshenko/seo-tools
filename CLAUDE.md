## Проект

SEO SaaS. Монорепо pnpm workspaces.

## Стек

## Стек

- TypeScript везде
- Backend: NestJS, PostgreSQL, Prisma, Swagger, class-validator, class-transformer, Zod (apps/api)
- Frontend public: Next.js App Router: маркетинг, лендинг, SEO (apps/www)
- Frontend private: React + Vite, React Router, React Hook Form,
  Zod, TanStack Query, Mantine UI, openapi-react-query (apps/app)
- Инфра: Docker

## Фичи

- Auth: email+пароль (подтверждение кодом), восстановление пароля, OAuth (Google, GitHub, Yandex)
- Подписки, тарифы, баланс
- Проекты пользователя
- Ключевые фразы: ручное добавление, загрузка с частотой
- Парсинг через сторонний API: Wordstat, Direct, выдача, подсказки
- Кластеризация ключевых фраз на фронте (по выдаче), результат сохраняется на бэке
- Ручное перемещение фраз по папкам
- Сбор и история позиций
- Генерация ТЗ на текст по группам фраз
- Проверка оптимизации страниц по ТЗ

## Роль и формат

- Я обучаюсь делая проект — цель понять архитектуру и практики, не только получить результат
- Объясняй решения и почему именно так, указывай на трейдоффы
- Указывай на антипаттерны
- Когда пишешь код — комментируй ключевые решения
- Когда скидываю свой код — делай code review
- Задавай уточняющие вопросы если моё решение неоднозначно

## Важно

Не пиши и не редактируй файлы сам. Жди явной команды типа "напиши", "создай", "добавь в файл". Если я задаю вопрос — отвечай текстом, не трогай файлы.
